# Trendydice — Portfolio Archive

> Portfolio snapshot of the original Trendydice website implementation built during my time working on the brand's early web presence.

This repository is preserved as a personal portfolio project and reference for my work as a software developer. It reflects the original site build and not the current live production code maintained by the company.

## Project archive / portfolio copy

This project represents the first version of the Trendydice website that I helped build for the company during its early stage. It includes the landing pages, storefront-style sections, product exploration flow, blog layout, and brand-first marketing pages used to present the brand online.

## My role

I worked on the frontend implementation of the brand website, shaping the user experience and building the early web presence for the company.

## Highlights

- Responsive marketing website for a brand-focused e-commerce business
- Landing page and product category navigation across apparel, accessories, and trophies
- Blog and policy pages to support the company’s content and trust-building flow
- Frontend implementation using React and Vite with a structured component-based architecture
- SEO-friendly SPA structure and routing for multi-page browsing

## Tech stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- Express server integration
- Netlify deployment setup

## Project structure

- `client/` — frontend pages and components
- `server/` — lightweight Express server for API endpoints
- `shared/` — shared API types and interfaces
- `netlify/` — Netlify function configuration
- `public/` — static public assets

## Local development
